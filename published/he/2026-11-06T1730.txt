🧠 שיחה ארוכה ב-Claude Code נדחסה לסיכום, ופתאום קלוד שכח כללים של הפרויקט?

הדחיסה מפנה מקום בחלון ההקשר, אבל לפי התיעוד היא יכולה לאבד פרטים חשובים. הפתרון הוא הוק מסוג SessionStart עם matcher בשם compact, שרץ אחרי כל דחיסה. כל מה שהפקודה שלו מדפיסה נכנס חזרה להקשר של קלוד.

מוסיפים לקובץ .claude/settings.json בתיקיית הפרויקט:

"hooks": { "SessionStart": [ { "matcher": "compact", "hooks": [ { "type": "command", "command": "echo 'תמיד להריץ בדיקות לפני commit'" } ] } ] }

אפשר להחליף את ה-echo בכל פקודה, למשל git log --oneline -5 לחמשת הקומיטים האחרונים.

למה זה שווה את הזמן שלכם: הכללים החשובים חוזרים לבד אחרי כל דחיסה, בלי להקליד אותם מחדש.

מקור: התיעוד הרשמי, code.claude.com/docs/en/hooks-guide
