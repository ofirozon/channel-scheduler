🔗 חיברתם שרת MCP שעובד מצוין, וכל אחד בצוות מתקין אותו מחדש לבד.

MCP הוא הפרוטוקול שדרכו Claude Code מתחבר לכלים חיצוניים. במקום שכל אחד יגדיר לעצמו, אפשר להוסיף את השרת בהיקף הפרויקט:

claude mcp add --transport http shared-server --scope project https://example.com/mcp

ההגדרה נשמרת בקובץ .mcp.json בשורש הפרויקט, והוא נועד להיכנס לניהול הגרסאות. כל מי שמושך את הריפו מקבל את אותם חיבורים, ובסשן אינטראקטיבי הוא רואה קודם דיאלוג אישור ולא מתחבר אוטומטית.

הפרט שמונע דליפה: הקובץ תומך בהרחבת משתני סביבה בסגנון ${API_KEY}. הכתובת נכנסת לריפו, הטוקן נשאר אצל כל אחד במחשב.
