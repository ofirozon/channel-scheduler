🪝 מדריך מיני: להריץ פורמט אוטומטי אחרי כל עריכה של קלוד

הבעיה מוכרת. קלוד כותב קוד תקין אבל בסגנון שלו, ואתם מיישרים אותו ידנית אחר כך. Hook פותר את זה: זו פקודה שרצה תמיד באירוע מסוים, בלי שהמודל יחליט אם היא מתאימה.

1. ודאו שמותקן אצלכם jq, הכלי שקורא JSON בטרמינל. במק: brew install jq

2. פתחו את קובץ ההגדרות settings.json בתיקיית claude של הפרויקט.

3. הוסיפו בתוכו את הבלוק הזה:

"hooks": {
  "PostToolUse": [
    {
      "matcher": "Edit|Write",
      "hooks": [{ "type": "command", "command": "jq -r '.tool_input.file_path' | xargs npx prettier --write" }]
    }
  ]
}

4. הקישו /hooks בשיחה. נפתח דפדפן ההוקים, ושם צריך להופיע מונה ליד PostToolUse. זו הבדיקה שההגדרה נקלטה.

5. בקשו מקלוד לערוך קובץ ופתחו אותו. הוא אמור לצאת מפורמט. כשההוק מצליח קלוד לא כותב על זה כלום בשיחה, אז הקובץ עצמו הוא ההוכחה.

מה קורה כאן: PostToolUse רץ אחרי שכלי הצליח, המסנן Edit ו-Write מגביל אותו לכלי עריכת קבצים בלבד, ו-jq שולף את הנתיב של הקובץ שנערך ומעביר אותו ל-prettier.

למה זה שווה: הכלל מפסיק להיות בקשה שקלוד אולי יזכור, והופך למשהו שקורה בוודאות.
