🔐 הפעלתם ארגז חול ל-Claude Code ונרגעתם? הפקודות בתוכו עדיין קוראות את מפתחות ה-SSH שלכם.

לפי התיעוד הרשמי, ארגז החול (/sandbox) מגביל כתיבה ורשת, אבל כברירת מחדל פקודה בתוכו קוראת את רוב המחשב, כולל ~/.ssh ו-~/.aws/credentials. אין רשימת חסימה מובנית: נחסם רק מה שאתם מגדירים.

מוסיפים ל-~/.claude/settings.json:

{
  "sandbox": {
    "enabled": true,
    "credentials": {
      "files": [{ "path": "~/.ssh", "mode": "deny" }],
      "envVars": [{ "name": "GITHUB_TOKEN", "mode": "deny" }]
    }
  }
}

הקבצים נחסמים לקריאה, ומשתני הסביבה נמחקים לפני כל פקודה.

שימו לב: זה חל רק על פקודות טרמינל בארגז. כלי הקבצים של קלוד, הוקים ושרתי MCP רצים מחוץ לו.

למה זה שווה את הזמן שלכם: כמה שורות, והמפתחות שלכם מחוץ להישג של כל פקודה בארגז.

מקור: code.claude.com/docs/en/sandboxing
