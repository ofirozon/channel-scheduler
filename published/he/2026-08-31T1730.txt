🧠 קלוד עורך קובץ, ושגיאת הטיפוס מתגלה רק בהרצה הבאה.

ב-Claude Code יש תוספי code intelligence שמחברים שרת שפה, אותה טכנולוגיה שמאחורי הקפיצה להגדרה ב-VS Code. מתקינים בפקודה /plugin install typescript-lsp@claude-plugins-official, והיא פותחת את פרטי התוסף כדי שתבחרו היקף התקנה. יש גם pyright-lsp לפייתון, rust-analyzer-lsp ו-gopls-lsp. את הבינארי של שרת השפה מתקינים בנפרד, התוסף לא עושה את זה בשבילכם.

למה זה שווה: אחרי כל עריכה של קלוד שרת השפה מחזיר לו שגיאות ואזהרות, אז טיפוס שגוי או import חסר נתפסים ומתוקנים באותו תור, בלי שתריצו קומפיילר. Ctrl+O מציג לכם את האבחונים.

מקור: https://code.claude.com/docs/en/discover-plugins
