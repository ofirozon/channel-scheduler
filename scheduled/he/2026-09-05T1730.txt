🛠️ אתם רוצים סוכן משלכם, ולא לכתוב את לולאת הכלים מאפס.

המנוע שמריץ את Claude Code זמין גם כספרייה, בשם Agent SDK, ל-Python ול-TypeScript בלבד. מתקינים עם pip install claude-agent-sdk או עם npm install @anthropic-ai/claude-agent-sdk, מגדירים את משתנה הסביבה ANTHROPIC_API_KEY, וקוראים לפונקציה query עם פרומפט ועם רשימת הכלים שמותר לסוכן להפעיל. מכאן הלולאה רצה לבד: קלוד קורא קבצים, מריץ פקודות, עורך, ומזרים לכם הודעות עד שהמשימה נגמרת.

הכלים המובנים, ה-Hooks, סוכני המשנה, ההרשאות והסקילים והזיכרון מתיקיית ה-.claude של הפרויקט עובדים בדיוק כמו ב-Claude Code. שווה לדעת: האימות הוא במפתח API מה-Console ולא במנוי claude.ai, ואנתרופיק לא מאפשרת למפתחים חיצוניים להציע התחברות עם מנוי במוצרים שלהם אלא באישור מראש.

למה זה שווה את הזמן שלכם: אתם מקבלים ניהול הקשר, ביצוע כלים וניסיונות חוזרים בלי לממש אותם.
