💳 יש לכם מנוי בתשלום, ויכול להיות שהוא בכלל לא זה שמחויב.

ב-Claude Code, אם משתנה הסביבה ANTHROPIC_API_KEY מוגדר אצלכם ואישרתם אותו פעם אחת בהודעה שקפצה, הוא גובר על ההתחברות עם המנוי שעשיתם עם /login. התוצאה: העבודה מחויבת לפי טוקנים בחשבון ה-Console, בזמן שהמנוי שאתם משלמים עליו יושב בצד ולא בשימוש.

איך בודקים, בשלושים שניות: מריצים /status. שורת Login method מציגה את חשבון המנוי, ושורת API key מופיעה רק כשמפתח API הוא שמשמש בפועל. אם היא שם ולא התכוונתם לכך, מריצים בטרמינל unset ANTHROPIC_API_KEY ופותחים סשן חדש. אפשר גם לשנות את האישור דרך המתג Use custom API key ב-/config.

למה זה שווה את הזמן שלכם: בדיקה חד פעמית שיכולה לחסוך חשבון API שאתם משלמים עליו במקביל למנוי.
