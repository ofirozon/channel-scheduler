🛑 נתתם ל-Claude Code לעבוד במצב האוטומטי, אבל push לריפו אתם רוצים לאשר בעצמכם.

לפי התיעוד, המצב האוטומטי מאשר כברירת מחדל push לכל ענף בריפו שאתם עובדים בו, כולל הענף הראשי, וגם פתיחת PR.

הפתרון: כלל ask בקובץ ההגדרות, למשל ~/.claude/settings.json. הוא נבדק לפני המסווג ותמיד מקפיץ בקשת אישור, גם במצב האוטומטי:
"permissions": {"ask": ["Bash(git push *)", "Bash(gh pr create *)"]}

כל השאר ממשיך לרוץ לבד.

שימו לב: הכלל תופס רק פקודה שמתחילה ב-git push. גרסה כמו git -C <dir> push עוברת בלי לעצור. ובקשה בשיחה ("אל תדחוף עד שאבדוק") עלולה ללכת לאיבוד בדחיסת הקשר, כלל בקובץ לא.

למה זה שווה את הזמן שלכם: שתי שורות, ופקודת push רגילה לא יוצאת בלי אישור שלכם.
