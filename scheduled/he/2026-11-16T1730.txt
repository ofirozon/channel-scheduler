🧪 קלוד מריץ עשרות פקודות אחת אחרי השנייה, ואתם מחכים?

ב-Claude Code גרסה 2.1.323 (12.11.2026) נוסף Code Mode, מצב ניסיוני שכבוי כברירת מחדל. במקום לקרוא לכל כלי בנפרד ולחכות לתוצאה, קלוד כותב קטע JavaScript שמריץ כמה פקודות במקביל, מעביר תוצאה מאחת לשנייה ומחזיר רק את מה שצריך.

מפעילים:
CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude

ומאשרים בשאלה שמופיעה. את הקוד עצמו רואים ב-Ctrl+O.

מתאים לשינוי שחוזר בהרבה קבצים או לחיפוש שצריך לסנן. שימו לב: רק בטרמינל, לא עם claude -p ולא ב-VS Code, וסשן כזה ממשיכים רק כשהמצב דלוק.

מקור: code.claude.com/docs/en/code-mode
