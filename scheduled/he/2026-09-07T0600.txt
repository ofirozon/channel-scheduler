ב-Claude Code, כוכבית בכלל של Bash מחליפה כל טקסט, כולל רווחים, וכל מה שלפני הכוכבית הראשונה מותאם ככתבו. לכן המילים שלפניה הן מה שמגביל את הכלל.

Bash(git log *) מאשר רק פקודות git log. לעומת זאת Bash(git * main) מאשר גם git push origin main, וגם git -c core.fsmonitor=<script> diff main, כלומר הרצה של תוכנית ששמה נקבע בתוך הפקודה.

הכלל הפשוט: הכוכבית באה אחרי תת הפקודה ולא לפניה. מגרסה 2.1.246 קלוד גם מזהיר על זה בהפעלה. עוד נקודה: הרווח לפני כוכבית סופית הוא חלק מהכלל, ולכן Bash(ls *) לא מתאים ל-lsof, בעוד Bash(ls*) כן.

למה זה שווה את הזמן שלכם: דקה אחת ב-.claude/settings.json תחת permissions.allow, ואתם יודעים מה באמת אישרתם.
