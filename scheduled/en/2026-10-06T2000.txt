🖥️ Some sessions are easier to finish with a diff view and a mouse.

Type `/desktop` in the middle of one. Claude Code saves the session, opens it in the desktop app and exits the CLI. From v2.1.285, `claude --desktop` does it from the shell, on the current directory or a session picked with `--continue` or `--resume <id>`.

`/desktop` needs a Claude subscription login on macOS or x64 Windows, so API keys, Bedrock, Google Cloud and Foundry are out.

The way back is `/resume` inside Desktop, which lists your terminal sessions.

Start in the terminal, review in the window, and never explain the task twice.

Source: code.claude.com/docs/en/desktop, Claude Code CHANGELOG v2.1.285
