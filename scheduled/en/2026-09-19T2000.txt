🚫 Auto mode refused something, and you're not sure what.

Blocked actions don't vanish. Run `/permissions`, open the Recently denied tab, and press `r` on the one you want. It retries with an ordinary approval prompt.

The reason is usually dull. Since v2.1.205, a recursive forced delete aimed at a shell variable gets blocked:

`rm -rf "$BUILD_DIR"`

The classifier never sees command output, so if an earlier command set that variable, it can't tell what's about to go. Name the literal path and it goes through.

Worth it because: a denial is one keypress from running instead of a reason to leave auto mode.

Source: code.claude.com/docs/en/permission-modes
