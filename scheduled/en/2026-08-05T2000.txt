You can stack skills in a single message now.

Type `/write-tests /fix-issue 123` and both skills load, with the trailing `123` passed as $ARGUMENTS to each of them. Claude Code expands the first skill plus up to five more after it.

Expansion stops at the first token that is not an inline user-invocable skill. A skill that runs as a forked subagent, such as /code-review from v2.1.218, ends the run there, and that token and everything after it becomes the argument text.

Requires v2.1.199 or later. Before that, only the first skill loaded and the rest arrived as literal text.

Source: code.claude.com/docs/en/skills
