🔐 Your CI installs a plugin with `-y`. Accepting what, exactly?

Some plugins install by running a command their marketplace declares. Claude Code prints it and asks, but a pipe has nobody to answer, so scripts reach for `-y` and take whatever the catalog says. Since v2.1.271 you can accept one exact command:

`claude plugin install <name> --accept-command <sha256>`

That digest is the one `shownCommand` reported in an earlier `--json` run. If the command, the plugin or the catalog changed since, it won't match, and the install stops and shows you the new command.

Worth it because: an install script that fails loudly if the approved command gets swapped.

Source: code.claude.com/docs/en/plugins-reference
