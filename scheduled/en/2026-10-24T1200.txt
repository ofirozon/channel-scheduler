🐧 Your repo lives inside WSL, and Claude Desktop crawls through it from Windows.

From Windows, those files sit behind a network filesystem. It's slow, and file watching breaks.

Run the session inside the distro instead. In a new Code tab session, open the environment picker, pick your distro under WSL, then choose the folder by its Linux path:

`/home/you/project`

Claude Code, its tools and git now run in Linux. You need WSL 2, and git inside the distro.

The integrated terminal and plugins don't work there yet, so I'd keep a WSL terminal open next to it.

Same project, minus the network filesystem in the middle.

Source: code.claude.com/docs/en/desktop-wsl
