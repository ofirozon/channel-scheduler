🧩 That shiny mod you're about to install can approve tool calls for you.

Mods landed in Claude Code v2.1.287 on October 1, on by default. They're JavaScript handlers that run inside Claude Code, so they can draw panes, restyle the interface, or step into a tool call before it runs.

They aren't sandboxed. A mod can read your files, hit the network, and approve a call your `ask` rule would have stopped. So clone it first and run:

`claude plugin validate ./some-mod`

The `calls:` line lists everything it reaches for. A token chart calling `$.http.fetch` is one I'd ask questions about.

Source: code.claude.com/docs/en/plugins/mods/overview
