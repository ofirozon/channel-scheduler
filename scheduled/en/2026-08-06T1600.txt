🔒 When did you last run `claude --version`?

Claude Code 2.1.221 closes a Bash permission check bypass: zsh could execute hidden commands inside `[[ ]]` regex conditionals, walking straight past your allowlist. Those commands now prompt for permission like everything else.

Run `claude update` if you're behind. Native installs pull it in the background and apply it on restart.

The one group that won't get it quietly: if you set `DISABLE_AUTOUPDATER` to pin a scheduled job, this doesn't reach you until you update by hand.

Worth it because: an allowlist you trust should actually hold.

Source: Claude Code changelog, 2.1.221
