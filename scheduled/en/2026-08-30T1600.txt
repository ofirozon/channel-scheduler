📱 You think of the fix on the bus. Then what?

You text it to Claude Code. It's called a channel, it takes five minutes to set up, and you need Bun installed.

1. Message BotFather on Telegram, send `/newbot`, pick a display name and a username ending in `bot`. Copy the token it gives you.

2. In Claude Code, run:
`/plugin install telegram@claude-plugins-official`
Pick the user scope so it works in every project. If it says the marketplace isn't found, run `/plugin marketplace add anthropics/claude-plugins-official` and retry.

3. `/telegram:configure <your token>`

4. Quit Claude Code and relaunch it with the channel on:
`claude --channels plugin:telegram@claude-plugins-official`

5. Send your bot any message. It answers with a pairing code. Back in the terminal:
`/telegram:access pair <code>`
`/telegram:access policy allowlist`

Now message it from your phone. The answer comes back in the chat and the work happens on your real files.

What trips people up: your bot only listens while that session is running with `--channels`. Close the terminal and it goes quiet.

Research preview, and it needs a claude.ai or Console login.

Worth it because: the ten-minute fix you thought of on the train doesn't have to wait until you're home.

Source: code.claude.com/docs/en/channels
