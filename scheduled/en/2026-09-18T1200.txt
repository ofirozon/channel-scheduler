🧠 Four hours in, Claude quietly stops following your API conventions.

A rule file in `.claude/rules/` with `paths:` frontmatter loads only when Claude reads a matching file. That's the point, and why it vanishes: it lives in the conversation, so a compact summarizes it off.

After compacting, Claude Code re-reads up to five files, most recently modified first, and reloads their matching rules. Yours returns only if one qualifies.

If a rule has to hold all session, drop the `paths:` block or move it into project-root CLAUDE.md. That one is re-injected from disk.

Worth it because: the rule you can't lose survives a compact you never saw.

Source: code.claude.com/docs/en/context-window
