🐢 Your MCP export tool takes four minutes. Your session doesn't have to wait.

When a tool call in the main conversation is still running after two minutes, Claude Code moves it to a background task. Claude gets the task ID, keeps working, and picks up the result when it lands. It shows in `/tasks`, where you can stop it.

Two minutes is too long for your slow tool? Set the threshold in milliseconds:

`export CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS=30000`

`0` turns it off. Stopping a task cancels the call, but the server may have done the work, so don't treat it as an undo.

The slow report runs, and you keep going.

Source: code.claude.com/docs/en/mcp#automatic-backgrounding-of-long-tool-calls
